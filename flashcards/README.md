# Flashcard study page

This folder holds the [flashcard study page](https://webnrrd2k.github.io/lbcc-electrical-study-materials/flashcards/) (`index.html`) and the deck list it reads (`index.json`). Open the link to study; the page only works on the website, not on GitHub.

`index.json` is generated by `tools/flashcards/build_decks.py`. Don't edit it by hand. The decks themselves live in each class's `flashcards/` folders.
