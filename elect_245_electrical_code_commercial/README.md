# ELECT 245 — Electrical Code: Commercial

Study guides and flashcards for ELECT 245, which works through the NEC as it applies to commercial buildings. Chapters follow the textbook *Electrical Wiring: Commercial*, 18th edition (Cengage, 2024), written to the **2023 NEC**.

Each flashcard deck can be studied right on its page, on the [flashcard study page](https://webnrrd2k.github.io/lbcc-electrical-study-materials/flashcards/), or downloaded for Anki, Quizlet or Emacs org-drill. Many cards include an original diagram.

The cards and diagrams are original study material. NEC section numbers refer to NFPA 70, but the code text itself is not reproduced. Cards tagged `beyond-text` go past what the textbook covers; check those in your own code book.

---

## Tips

- **Read the code book, not just the cards.** Quizzes and the licensing exam expect you to find the section yourself.
- **Watch the edition.** These materials follow the 2023 NEC. Section numbers and thresholds can change between editions; for example, the 2023 NEC added a 601–1000 V row to Table 110.26(A)(1).
